Claude Desktop App

A native application for Windows and macOS that consolidates three distinct work modes in one place — Chat for quick conversation, Cowork for complex multi-step tasks, and Code for software development. Unlike the web browser version, the Desktop App integrates directly with local files, system tools, and development environments on your machine.

Conversational Assistant
Same Claude experience as claude.ai — optimized for quick exchanges, iterative drafting, and back-and-forth Q&A.

  • Connect external tools (Google Drive, Notion, etc.)
Cowork

01 / Meet Claude

Claude Chat

Conversational AI for everyday tasks — accessible via browser at claude.ai or through the Claude Desktop App on Windows.

  • Ask and iterate: Type any question, request, or task. Claude responds in natural language and handles multi-turn follow-ups and revisions in the same session.
  • File upload and analysis: Attach documents, spreadsheets, images, and PDFs directly into the chat. Claude reads and references file content in its responses — up to 200K tokens (~500 pages) per session.
  • Screenshot analysis: Use Windows Snipping Tool (Win+Shift+S), capture your screen, paste into Claude, and ask it to interpret dashboards, error messages, or UI layouts.
  • Connectors: Link Claude to cloud services (Google Drive, Notion, Slack) so it can pull relevant context from your connected tools into the conversation.

01 / Meet Claude

Claude Cowork

An agentic work mode for complex, sustained tasks — research, cross-source analysis, and producing finished documents — where Claude works independently across multiple data sources simultaneously.

  • Folder access: Give Claude a folder; it reads what's relevant, executes tasks, and saves output back to the same location.
  • Subagents & multitasking: Claude breaks large tasks into parallel sub-tasks — multiple research threads running simultaneously.
  • Scheduled tasks: Automate recurring work (daily briefings, weekly roundups, inbox triage) on a defined schedule.
  • Browser use: When connected to Chrome, Claude navigates websites, reads pages, and incorporates findings into the task.
  • Plugins: Extend Cowork's capabilities with live financial data, internal knowledge bases, or compliance frameworks.

01 / Meet Claude

Claude Code

An agentic coding tool that works directly inside your codebase — reading, writing, and executing code through natural language instructions. Not a suggestion engine; it makes real file changes and runs real commands.

  • Three interaction modes: Ask (propose every change for approval), Code (auto-apply file changes, confirm terminal commands), Plan (outline full approach before touching anything).
  • Local or remote: Work directly in local folders, or connect a GitHub repository for cloud-based sessions that continue even when the app is closed.
  • Visual diffs & git integration: Every change is tracked. Review diffs, accept or reject, and roll back at any point.
  • Runs in your environment: Terminal, VS Code, JetBrains, or browser-based. Claude reads, writes, and executes commands within your project.

Work & Knowledge

Skills define repeatable workflows. Projects store persistent knowledge. Artifacts are the structured outputs Claude generates — each serving a distinct function in a professional workflow.

02 / Organize

Working with Skills

Reusable instruction packages that teach Claude how to execute your specific workflows — so you get consistent, on-standard output every time without re-explaining the process from scratch.

What you can do with Skills: Automate monthly status report generation in your team's exact format. Ensure every presentation follows Samsung brand and visual standards. Structure meeting notes consistently across all participants. Generate legally compliant documents from templates — all triggered with a single command.

🔧 Anthropic Skills (Built-in)
Pre-built by Anthropic. Covers enhanced document creation for Excel, Word, PowerPoint, and PDF. Available to all paid users — Claude invokes them automatically when you request a relevant file type. No setup required.
🏗️ Custom Skills (Organization-built)
Built by you or your team for specialized workflows — e.g., applying Samsung brand guidelines to decks, structuring weekly reports, or running a standard data analysis process. Created via conversation with Claude; no coding needed.

02 / Organize

Claude Projects

Persistent workspaces where Claude retains your uploaded documents, instructions, and conversation history — so it always has the context it needs without you re-uploading files each session.

What you can do with Projects: A product manager uploads all Q4 specs, meeting notes, and competitive analysis once — then asks Claude questions across all of them at any time. An engineering team keeps technical docs in a shared project so Claude always understands the full codebase context. A legal team stores all contract templates and precedents so Claude drafts consistently to standard.

📂 Project Knowledge
Upload PDFs, DOCX, CSV, HTML, and more. Claude references these across all conversations in the project — eliminating repeated file uploads. Name files descriptively; Claude uses filenames to retrieve relevant content.
📋 Project Instructions
Define tone, expertise level, response format, and task-specific requirements. Instructions apply to every conversation in the project — ensuring consistent output style across team members.
📈 Automatic Scaling (RAG)
When knowledge base approaches the context window limit, Claude automatically enables Retrieval Augmented Generation (RAG) — expanding capacity by up to 10× while maintaining response quality.
👥 Team Collaboration (Team/Enterprise)
Three permission levels: View (read-only + chat), Edit (modify instructions, knowledge, members), Owner (full control + visibility settings). Share to individuals or entire organization.

Skills vs. Projects

Two features that look similar but serve different purposes — one stores knowledge, the other encodes process.

Projects store knowledge — reference materials Claude draws on across conversations.

Skills perform tasks — repeatable procedures Claude executes consistently.

The two complement each other: a Skill can reference knowledge stored in a Project.

📁 Projects

Best for

Persistence

⚡ Skills
Purpose
Define processes Claude executes step-by-step
Best for
Repeatable workflows, multi-step tasks, consistent methodology
Persistence
Instructions applied every time the skill is invoked
Example

02 / Organize

Creating with Artifacts

Standalone, interactive outputs that Claude generates in a dedicated side panel — rendered live so you can preview, edit, download, or share immediately without switching applications.

What you can do: Request a working Excel formula or Python script and download it directly. Get a fully formatted report template ready for immediate use. Build an interactive expense tracker or data dashboard. Generate a process flowchart from a text description. Share any artifact with colleagues via a single link — no Claude account required to view.

  • Documents: Markdown and plain text for reports, project plans, blog posts — immediately downloadable.
  • Code snippets: Working code in Python, JavaScript, C++, and more — copy or download for direct use.
  • HTML pages: Complete web pages (HTML + CSS + JS) for landing pages, prototypes, and interactive demos.
  • Diagrams: Mermaid-based flowcharts, sequence diagrams, Gantt charts, and org charts.
  • React components: Interactive UI elements with real logic — calculators, dashboards, data visualizations.

Artifacts can be shared internally (Team/Enterprise) or published publicly as a shareable link. Others can "remix" public artifacts into their own Claude session.

Connecting Tools with Claude

Model Context Protocol (MCP) — an open standard that allows Claude to connect to external tools, databases, and APIs. Think of it as a universal adapter (like USB-C) that lets Claude work directly inside the platforms your team already uses.

MCP is an open standard (analogous to USB-C for AI) that allows Claude to connect to external tools, databases, and APIs through a single consistent interface. Two connector types: Web connectors (cloud services) and Desktop extensions (local tools via the Desktop app).

Case 01

Compare Products
Across Sites

Claude in Chrome automatically navigates multiple product tabs, extracts specifications, normalizes inconsistent labels, and consolidates everything into a side-by-side comparison document.

Overview
Tell Claude which products to compare and which specs matter most. Open each product page in separate browser tabs — Claude navigates between them, extracts the data, and builds a normalized Google Docs comparison table.
Outcomes
  • →No manual tab-switching or copy-paste
  • →Inconsistent labels auto-normalized
  • →Category winner identified per spec
  • →Reviews & pricing added on follow-up
How It Works
1
Open each product page in a separate Chrome tab
No special setup — just browse to the product pages you want to compare (e.g. laptop specs, SaaS pricing, supplier catalogs) and keep each in its own tab.
2
Tell Claude what you need in the Chrome sidebar
"Compare these 4 laptops on processor, RAM, battery life, weight, and price — show which wins each category."
3
Claude reads each tab and normalizes the data
Automatically visits each product page, extracts specs, and maps inconsistent labels (e.g. "Memory" vs "RAM") to a unified schema — no copy-paste needed.
4
Review the Google Docs table & ask follow-ups
A formatted comparison table is created with category winners highlighted. Ask: "Add review scores" or "Which is the best value under $1,500?"
